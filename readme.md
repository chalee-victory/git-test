# 나만의 프롬프트 관리 프로그램

> 이 프로젝트는 Python/Git 학습용입니다.

GenAI 활용 과정에서 쌓인 다양한 프롬프트(텍스트 생성, 이미지 생성, 페르소나, 자동화 등)를
체계적으로 저장하고 관리할 수 있는 파이썬 콘솔 기반 프로그램입니다.

프롬프트를 추가하고, 카테고리별로 분류하고, 키워드로 검색하고, 자주 쓰는 항목은
즐겨찾기로 관리할 수 있습니다.

---

## 실행 방법

Python 3.10 이상이 설치되어 있어야 합니다.

```bash
python main.py
```

실행 후 화면에 나오는 메뉴 번호를 입력하여 원하는 기능을 선택합니다.

---

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력하여 새 프롬프트를 등록합니다. 빈 값은 재입력을 요청하며, 등록 전 Y/N 확인 절차를 거칩니다. |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 번호, 카테고리, 즐겨찾기 여부(⭐)와 함께 보여줍니다. |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 카테고리의 프롬프트만 보여줍니다. |
| 4 | 프롬프트 검색 | 키워드를 입력하면 제목 또는 내용에 포함된 프롬프트를 찾아줍니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력하면 해당 프롬프트의 전체 내용을 보여줍니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력하여 즐겨찾기를 추가하거나 해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기로 등록된 프롬프트만 모아서 보여줍니다. |
| 0 | 종료 | 현재 데이터를 `prompts.json`에 저장하고 프로그램을 종료합니다. |

---

## 프롬프트 카테고리

프롬프트는 다음 6가지 카테고리 중 하나로 분류됩니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

---

## 동명 항목 및 카테고리 처리 규칙

### 동명(제목 중복) 프롬프트 처리

- 제목이 동일한 프롬프트도 여러 개 등록할 수 있습니다.
- 별도의 중복 검사나 자동 병합 로직 없이, 입력된 순서대로 각각 독립적인 항목(리스트의 서로 다른 인덱스)으로 관리됩니다.
- 목록/검색 결과에는 제목이 같아도 모두 나열되며, 특정 항목을 구분해야 할 경우 상세 보기(5번) 기능의 **번호 기반 조회**를 통해 개별적으로 확인합니다.

### 카테고리 처리 규칙

- 기본 제공 카테고리는 **텍스트 생성 / 이미지 생성 / 영상 생성 / 페르소나 / 자동화 / 기타**의 6종입니다.
- 프롬프트 추가 시 사용자는 이 6종 중 선택하거나, 목록에 없는 새로운 카테고리명을 직접 입력할 수 있습니다.
- 직접 입력한 카테고리는 기본 카테고리와 **자동으로 병합·정규화되지 않으며**, 입력한 문자열 그대로 별도의 카테고리로 취급됩니다.
  - 예: "자동화"와 "사무자동화"는 철자·의미가 유사하더라도 서로 다른 카테고리로 관리됩니다.
- 카테고리 간 우선순위나 병합 규칙은 별도로 두지 않으며, **"입력값을 그대로 유지한다"**는 것을 이 프로그램의 설계 원칙으로 합니다. 이는 사용자가 자유롭게 카테고리를 확장할 수 있도록 하기 위한 단순화된 정책입니다.
- 카테고리별 조회(3번) 기능은 기본 6종 카테고리를 기준으로 동작하며, 사용자가 직접 입력한 카테고리는 프롬프트 검색(4번)이나 프롬프트 목록(2번)에서 확인할 수 있습니다.

## 보너스 기능 — 데이터 영속화 (JSON 저장/불러오기)

기본 요구사항은 "프로그램 종료 시 데이터 초기화"이지만, 이 프로그램은 `json` 모듈을 활용하여
**종료 후에도 데이터가 유지**되도록 확장하였습니다.

- **프로그램 시작 시**: `prompts.json` 파일이 있으면 그 내용을 불러와 시작합니다. (파일이 없으면 기본 데이터 4개로 시작)
- **프로그램 종료(`0`번) 시**: 현재까지의 모든 프롬프트(추가/삭제/즐겨찾기 상태 포함)를 `prompts.json`에 자동 저장합니다.

이를 통해 프로그램을 껐다 켜도 이전에 추가한 프롬프트와 즐겨찾기 상태가 그대로 유지됩니다.

> `prompts.json`은 실행 결과로 생성되는 개인 데이터 파일이므로 `.gitignore`에 등록하여
> 버전 관리 대상에서 제외하였습니다.

## 예외 처리

- 잘못된 메뉴 번호를 입력하면 안내 메시지를 출력하고 다시 메뉴를 보여줍니다.
- 프롬프트 추가 시 제목이 비어 있으면 등록을 취소하며, 내용/카테고리가 비어 있으면 재입력을 요청합니다.
- 상세 보기, 카테고리별 조회, 즐겨찾기 관리에서 존재하지 않는 번호나 숫자가 아닌 값을 입력하면
  `try / except`로 안전하게 처리하여 프로그램이 중단되지 않고 메뉴로 복귀합니다.
